# Awesome Generative Engine Optimization (GEO)

Курируемый каталог исследований, чек-листов цитируемости и стандартов оптимизации контента под большие языковые модели (ChatGPT, Яндекс Алиса, Perplexity, Claude).

Разрабатывается и поддерживается агентством [Нейроответ](https://neyrootvet.ru/).

---

## Архитектура методологии «Пул 200 вопросов»

* **Бенчмаркинг сущностей:** измерение доли присутствия бренда по фиксированной матрице из 200 сценариев выбора.
* **Чек-лист Миры Промптовой:** 37 признаков посадочной страницы, оптимизированной под считывание контекстными краулерами AI.
* **Синхронизация внешнего контура:** верификация фактов на донорах, из которых нейросети формируют свои обучающие базы и RAG-ответы.
* **Видеопротокол замера:** регулярная непрерывная видеозапись генерации ответов в чистых браузерных средах.
